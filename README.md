## ✨ 功能介绍

### 🌳 智能世系图谱
- 自动生成可视化的家族世系图谱，清晰展示多代家族关系
- 支持 **横向/纵向** 多种布局，适配不同家族的展示需求
- 交互式图谱操作：拖拽、缩放、节点高亮，方便快速定位

### 🤖 AI 智能分析
- **家族数据分析**：基于 AI 对家族数据进行深度挖掘与统计
- **八字测算**：集成中国传统八字命理分析功能
- **遗传病史分析**：对家族遗传病史进行追踪与风险评估

### 📄 多格式导出
- 一键导出 **PDF** 家谱文档，支持高质量印刷
- 支持 **图片**、**HTML** 等多种格式，方便分享与存档

### 🖥️ 跨平台支持
- **Web 端**：浏览器即可访问，随时随地查看
- **桌面端**：基于 Electron 构建，支持 Windows / macOS / Linux
- 本地数据存储，安全可靠，无需担心隐私泄露

### 🎨 现代化界面
- 基于 React + shadcn/ui + Tailwind CSS 构建的精致 UI
- 支持 **亮色/暗色** 主题切换
- 中文字体优化，完美支持繁体/简体中文显示

### 📊 其他特性
- 家族成员 **基本信息管理**：姓名、生卒、生平、照片等
- **多语言支持**：内置国际化 (i18n) 框架
- 数据 **本地加密存储**，保护家族隐私
- 管理员密码保护，防止误操作
